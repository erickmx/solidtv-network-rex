# Game Rules:

## 1. Start the Game:

- Press the 'Play' button to start the game.
- The game will start with a new game state.
- The game will display a new dessert scene.
- The score board will be displayed at the top right of the screen.

## 2. Game State:

The game state will be managed by the game engine. The game state will be updated based on the user's input.

## 3. Keyboard Controls:

~~'Space': Jump~~ since will be managed via tv remote the common keyboard inputs won't be used.

- 'Up Arrow': Jump.
- 'Down': Crouch.
- 'Right': Move Right.
- 'Left': Move Left.


## 4. Game Elements:

- **Player**: The player is a dinosaur that can jump and crouch.
- **Cacti**: The primary obstacle. Players must jump over these to avoid collision. Cacti appear in varying heights and combinations.
- **Birds**: These creatures fly horizontally across the screen in a set pattern. Players can jump over them to avoid collision.
- **Pterodactyls**: Flying obstacles that appear at higher altitudes. Players must time their jumps carefully to avoid collision.
- **Score Board**: Displays the player's current score, updating in real-time as the player progresses.
